# customer_behavior_analysis
End-to-end Customer Behavior Analysis using Python, SQL, and Power BI for data cleaning, exploratory data analysis, KPI analysis, and interactive dashboard creation.

## 📌 Project Overview

This is an end-to-end Data Analytics project that analyzes customer purchasing behavior using **Python, PostgreSQL/MySQL, and Power BI**. The project includes data cleaning, exploratory data analysis (EDA), SQL-based analysis, and an interactive Power BI dashboard to uncover valuable business insights and support data-driven decision-making.

---

## 📂 Dataset

The dataset contains customer purchase information, including:

- Customer ID
- Age
- Gender
- Location
- Product Category
- Purchase Amount
- Purchase Frequency
- Payment Method
- Customer Rating
- Purchase Date

## 🚀 Project Workflow

### 1. Data Loading
- Imported the dataset into Python using Pandas.

### 2. Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Corrected data types.
- Standardized text values.
- Created new calculated columns.

### 3. Exploratory Data Analysis (EDA)
- Customer demographics analysis
- Purchase frequency analysis
- Spending pattern analysis
- Product category analysis
- Customer rating analysis
- Payment method analysis

### 4. SQL Analysis
Performed SQL queries to analyze:
- Total Sales
- Average Purchase Amount
- Top Customers
- Product Category Performance
- Customer Segmentation
- Monthly Sales Trend
- Gender-wise Analysis
- Purchase Frequency Analysis

### 5. Power BI Dashboard
Built an interactive dashboard including:
- KPI Cards
- Sales Trend
- Customer Segmentation
- Product Category Analysis
- Purchase Frequency Analysis
- Gender Distribution
- Payment Method Analysis
- Interactive Slicers and Filters
